ECS simplification benchmarks
Date: 2026-10-03
Baseline: 0fdbd194
Go: go1.26.0 linux/amd64
CPU: Intel Core i5-11500

Grouped runs: three samples per scenario, 300 ms each.
Paired runs: before/after, after/before, before/after; 500 ms each.
Component pair isolates the Get/GetRef/GetMut implementations.
HTML pair isolates ecs/html_component.go with the same final test harness.
Logs for paired runs are grouped below by implementation.
Benchmarks were not run concurrently with other tests, vet or builds.
Steady-state zero allocation excludes initial caches and capacity growth.
Button spawn benchmark includes a new World and 50 controls per operation.
Textarea benchmark has no font and isolates lookup/surface synchronization.
These are CPU microbenchmarks, not GPU, frame-time or FPS measurements.
