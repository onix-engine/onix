# Documentation

[English](README.md) | [简体中文](README.zh-CN.md)

Onix documentation is grouped by what you need to do:

| Category | Overview | Contents |
| --- | --- | --- |
| Usage | [Usage guide](usage.md) | Projects, modules, resources, builds, widgets and platform integration |
| Design | [Engine design](design.md) | Ownership, ECS, scheduling, rendering and HTML architecture |
| Performance | [Performance guide](performance.md) | Warm-path guarantees, measurement rules and optimization boundaries |

The overview pages are available in English and Simplified Chinese. Focused
reference guides contain API and platform details; code samples and API names are
language-neutral.

Process notes, one-off reviews, raw benchmark output and completed migration logs
are intentionally not kept here. Performance claims in the overview describe
current contracts, not historical before/after results.
