Onix ECS seventh batch benchmarks
Go 1.26.0; Linux amd64; GOMAXPROCS=6; 300ms x 3; serial runs.
MixedPatch compares sequential calls, prepared patches, and queued patches in the same final binary.
One round trip changes two component types in each direction and retains four columns.
Control benchmarks compare batch-six snapshot through Go overlay with the final code.
Spawner2OneThousand includes fresh-world creation and capacity growth; it is not a warmed allocation benchmark.
