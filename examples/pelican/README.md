# 鹈鹕快递 · 逆风海岸

一款使用 Onix 原生 2D 精灵和 HTML/CSS 界面实现的横向骑行小游戏。扮演海岸邮差阿鹈，骑着珊瑚红小轮车接住鲜鱼，送往沿途的灯塔小站。角色、单车、鱼、螃蟹、灯塔和海岸背景全部使用项目内原创 SVG，无外部素材或网络依赖。

在引擎仓库根目录运行：

```sh
cd examples/pelican
go run .
```

游戏使用 1280 × 800 逻辑视口，按比例适配窗口。可以使用键盘，也可以点击或长按屏幕按钮。

| 操作 | 键盘 | 触屏 / 鼠标 |
| --- | --- | --- |
| 起跳 | 空格、↑ 或 W | 按下「跳跃」或游戏区域 |
| 滑翔 | 下降时持续按住跳跃键 | 持续按住跳跃按钮或游戏区域 |
| 空中翼扑 | 松开后再次按下跳跃键 | 松开后再次按下 |
| 投递 | X 或 D | 点击「投递鲜鱼」 |
| 暂停 / 继续 | P 或 Esc | 点击右上角按钮 |
| 重新开始 | R | 点击结算或暂停面板中的「重新出发」 |

- 自动向前骑行，路线共 15.6 km，经过贝壳湾、风车岬和灯塔海岸三个区域，后半程会遇到周期性逆风。
- 沿鱼群起跳，嘴袋最多装 6 条鱼。鱼越多，起跳越低；每次离地期间可以消耗 1 条鱼额外翼扑一次。长按跳跃可减缓下降并略微加速。
- 接近六座灯塔小站时会亮起投递提示。按 X 或点击按钮，一次送出嘴袋内的全部鲜鱼。每座小站只能签收一次，空袋不能投递。
- 每条送达的鱼获得 100 分，连续投递依次额外获得 50、100、150…分。满袋投递再加 200 分，每次成功投递都会触发 3.5 秒冲刺。
- 螃蟹和木箱需要跳过。碰撞损失一格车况和至多两条鱼，中断连续投递加分，并获得 1.8 秒保护时间。三格车况耗尽即结束。
- 骑到终点时每格剩余车况加 150 分，送达至少 18 条鱼再加 1000 分。接到鱼本身加 10 分。最佳积分保留于本次运行期间。

美术资源、项目清单和场景 JSON 均在 `resources/` 中。轮子、曲柄、翅膀、嘴袋、投递飞鱼和星形反馈分别动画，背景采用视差滚动。固定容量数组保存路线、可见精灵和粒子；游戏模拟及路线重置不分配堆内存，HUD 复用 DOM 句柄，仅在显示值变化时更新文字。

HUD 显式使用 `resources/game/fonts/` 中随包发布的常规和粗体中文字体，在 Web 上也不依赖系统字体。字体由仓库内的 Noto Sans SC 按游戏源码和 HTML 使用的字符生成，保留 ASCII 供动态数字使用，许可证随资源打包。修改文案后，在安装了 FontTools 的 Python 环境中运行 `python3 examples/pelican/tools/subset_fonts.py` 重新生成字体；资源测试会检查字符覆盖。

渲染采用按需模式：骑行和输入改变画面时请求刷新，开始、暂停和结算界面静止后停止提交帧。SVG 按原始尺寸选择栅格化倍率：超过 25 万逻辑像素的背景使用 1 倍，其余精灵使用 2 倍；逻辑尺寸与 mipmap 保持一致。该策略在 `images.go` 中通过泛型解码器注入，重新生成注册代码不会覆盖它。当前 1280 × 800 视口下，三张背景的 RGBA8 纹理及 mipmap 合计从约 29.7 MiB 降到 7.4 MiB；高 DPI 窗口下的画质由人工验收。

2026-10-26 在 Linux / i5-11500 / llvmpipe 软件 Vulkan 下，关闭 pprof 的一次轻量对照采样如下。CPU 的 100% 表示一个逻辑核，内存为进程 RSS，初始化时间不含编译且未清理系统缓存。

| 指标 | 连续渲染、SVG 全部 2 倍 | 按需渲染、背景 1 倍 |
| --- | ---: | ---: |
| 开始界面 CPU | 47.3% | 2.6% |
| 暂停界面 CPU | 49.0% | 1.7% |
| 骑行 CPU / 实际 FPS | 116.7% / 25.4 | 106.0% / 28.8 |
| 骑行 RSS | 210.1 MiB | 183.1 MiB |
| 初始化至运行循环前 | 1.34 s | 0.89 s |

每个进程依次测量开始界面 5 秒、骑行 6 秒、暂停 5 秒，跳过阶段切换后的预热窗口。另两轮含 pprof 的原版/修改版对照中，骑行 RSS 分别为 208–210 / 186–190 MiB，静止 CPU 为 45–52% / 1.9–2.3%；实际帧率存在波动，骑行 CPU 不能脱离 FPS 单独比较。这些是短时软件渲染数据，不代表硬件 GPU 或 Android 的表现。

从仓库根目录校验、重新生成注册代码并运行定向测试：

```sh
go run ./editor/cmd/onix check ./examples/pelican
go run ./editor/cmd/onix generate ./examples/pelican
go test ./examples/pelican ./examples/pelican/resources/game
```

测试覆盖完整路线可通关性、负重跳跃、滑翔与翼扑、碰撞保护、投递与奖励、暂停重开、输入去重、零分配模拟，以及真实项目的 SVG 分辨率策略、按需出帧、HUD 布局和键盘/按钮事件路由。视觉验收由人工完成，不启动编辑器做截图测试。
